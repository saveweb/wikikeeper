# WikiKeeper

WikiKeeper tracks MediaWiki installations by periodically collecting:

- statistics history
- extensions and skins history
- wikidump backups on archive.org

The purpose of this project is simply to index MediaWiki sites for Wikiteam/ArchiveTeam/STWP so that we can easily find the wikis that are most urgently needed for archiving.
